# 踩坑记录

## tensor 热身练习

- `split(n)` 的参数是**每块的长度**，不是块数；想按块数切用 `chunk(n)`。
- 拆头不能直接 `view(B, nh, T, hs)`：要先 `view(B, T, nh, hs)` 再 `transpose(1, 2)`，否则数据会切错位置，而且不报错。
- `masked_fill(cond, v)` 填的是 `cond` 为 True 的位置；因果 mask 要填未来位置，用 `mask == 0`。
- 因果 mask 填 `-inf` 而不是 0：softmax 里 e^(-inf) = 0，被遮住的位置权重才是 0。
- `transpose` 等操作返回新张量，不修改原张量，结果要赋值。
- `transpose` 之后内存不连续，`view` 会报错，需要先 `.contiguous()`（或用 `reshape`）。


## model.py

- `.T` 只对二维矩阵才是需要的"转置"。对四维张量 (B, nh, T, hs)，它会把所有维度的顺序整个倒过来，变成 (hs, T, nh, B)。
- `mask = torch.tril(torch.ones(T, T))`默认把mask建在CPU上，在使用显卡时两者混用会报错，改为`mask = torch.tril(torch.ones(T, T, device = x.device))`
